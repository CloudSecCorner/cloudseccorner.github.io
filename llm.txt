Cloud Security Corner: Agentic AI & Cloud Security
=====================================

This project is a community-driven resource hub for securing AI agents, autonomous cloud workloads, and the infrastructure they can access. Its main topics are agent identity and authorization, tool isolation, runtime defense, AI red teaming, threat modeling, governance, and incident response.

The site includes:
- Hands-on Labs
- Research and Field Notes
- A Curated Agentic AI and Cloud Security Tools Directory

---

Labs
----
- Agentic Cloud Security Essentials: Threat-model an AI agent with cloud access and design controls for identity, tools, approval, isolation, observability, and response. [Link](https://cloudsecuritycorner.com/labs/Agentic-Cloud-Security)
- Ethical Hacker Easy Way: Introduction to ethical hacking principles and methodologies. [Link](https://cloudsecuritycorner.com/labs/ethical-hacker-easy-way)
- Threat Modeling: Learn how to create a threat model for a given system. [Link](https://cloudsecuritycorner.com/labs/Threat-Modeling)
- NMAP Practical Labs: Network scanner to identify open ports, services, and other network information. [Link](https://cloudsecuritycorner.com/labs/Nmap-Practical-Labs)
- Security Engineering Fundamentals: Understanding the core principles of security engineering and how to apply them to real-world scenarios. [Link](https://cloudsecuritycorner.com/labs/Security-Engineering-Fundamentals)
- Zero Trust Architecture: Exploring security model that assumes all users, devices, and applications are potentially hostile and must be verified. [Link](https://cloudsecuritycorner.com/labs/Zero-Trust-Architecture)
